Random Color Generator


The Random Color Generator is a simple JavaScript project that generates a new random RGB color whenever the user clicks a button. The generated color code is displayed on the screen, and the background color of a <div> changes to match the generated color. This project is a great beginner-friendly example of DOM manipulation, event handling, functions, and CSS styling with JavaScript.

Features
🎲 Generates a random RGB color with a single button click.
🖥️ Displays the generated RGB color code on the page.
🎨 Updates the background color of a <div> instantly.
⚡ Uses JavaScript event listeners for user interaction.
📚 Beginner-friendly and easy to understand.

Technologies Used
HTML
CSS
JavaScript 

How It Works
Open the project in a web browser.
Click the Generate Color button.
A random RGB color is created using JavaScript.
The RGB value is displayed on the page.
The background color of the color box changes to the newly generated color.
